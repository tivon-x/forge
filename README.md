# Forge

Forge is a provider-neutral coding agent CLI written in TypeScript.

The project is currently implementing the Phase 1 scope described in
[`docs/forge-implementation-plan.md`](docs/forge-implementation-plan.md).

## Requirements

- Node.js 24
- pnpm 11

## Development

```bash
pnpm install
pnpm typecheck
pnpm test
pnpm lint
pnpm build
```
